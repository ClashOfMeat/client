# Bronze Flex crest

The Flex effect uses the clean circular Bronze crest in
`apps/desktop/ui/assets/flex-fx/bronze-clean-source.png`. The shipped
`bronze.png` beside it is a 180 × 2400 sheet of twelve 180 × 200 frames.
Frames 0, 10 and 11 are transparent. Frames 1–9 scale and bounce the crest;
the score is drawn by `overlay.mjs` at a 153px baseline for Bronze.

The source came from built-in ImageGen result
`01a18854-fe3d-7cc3-893c-147cd91daa4a/exec-2d3af5dc-5e31-4951-b133-2116f860e98b.png`
using the existing Bronze badge as the reference. The selected result was
cropped to the medallion and reduced with nearest-neighbor sampling.

> Use case: precise-object-edit. Asset type: transparent pixel-art game rank
> crest reference for an existing animated Flex effect. Edit the supplied
> Bronze badge: remove the entire lower horizontal nameplate, small hanging
> side ornaments, ground shadow, and loose particles. Complete the bottom of
> the circular bronze medallion as a natural rounded rim in the SAME pixel-art
> style and bronze palette. Preserve the exact upper circular rim, central
> raised orb, four metal studs, shading, texture, and front-facing orientation.
> Keep generous transparent margins. No text, no number, no new decoration,
> no background, no glow. The round medallion must remain the only visible
> object.

Reviewed at native effect size: the crest remains centered, its bottom rim is
complete, and no nameplate, loose particles, or ground shadow appear in any
visible frame. The other Bronze rank assets remain as authored.
